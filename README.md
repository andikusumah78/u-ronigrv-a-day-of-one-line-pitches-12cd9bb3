[A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3)
— one sentence, 240 characters at most, that would convince a friend who has
never coded to let an AI agent build their first app idea on make.fun.

## The pitch

> Tell me the app you've been dreaming about and I'll have an AI agent build you a first working version on make.fun today — you just describe it in plain words, no code, no cost, no commitment.

192 characters.

## How it works

`main.py` (pure Python 3.13 stdlib, no network, deterministic) writes exactly
that sentence to `/output/entry.txt`.

```sh
python3 main.py
```
